### How I build

→ **A human approval gate, enforced in the state machine.** No agent output reaches a patient, a trader or a customer until a person clears it. It is architecture, not a prompt instruction.

→ **Scores that carry their reason.** The lead pipeline returns a score and why it scored, because an unexplained number is not actionable by whoever has to act on it.

→ **Idempotent scheduled jobs.** Things that re-run safely, because things that run unattended will re-run.

I call models through APIs and build the systems around them.
